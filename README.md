# Login UI

A responsive, dependency-free login page built with plain HTML, CSS, and
JavaScript.

## Preview locally

Open `index.html` in a browser, or serve the directory with any static file
server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Features

- Split-screen landing and sign-in layout
- Email/password form with client-side validation states
- Password visibility toggle
- Responsive styling for desktop and mobile screens
- Accessible labels, status messaging, and focus states
